备份目录保留至观察期结束（约 10 天）后再删；`%TEMP%` 会被磁盘清理扫走，观察期内不要跑清理。

### 恢复步骤（逐条可执行）

1. 停守护进程 + 关控制台（见 §4，禁止 taskkill）；
2. 把上表 4 个文件从 `%TEMP%\rl_rollbak_设备身份\` 复制回原位覆盖；
3. 重新启动（start.bat 或双击 ResinLoop.exe）。

**诚实边界**：回滚只恢复本地。服务端已经发生的 `deviceLogin/saveDevice` 注册**撤不回来**（星铁/绝区零的旧设备孤儿同理）。恢复 `mihoyo_binding.json` 会抹掉新身份的"已注册"记录，下次查询会对**同一**新 device_id 再注册一次——服务端语义是重新绑定同一设备，推断不产生新设备（GsCore 同款流程），但此点本身也属于本次联调的观察项。

## 4. 观察判据（带真实日志行格式）

日志看两处：控制台底部「运行日志」（双源合并版）或 `logs/dailycheck.log`。注意 `config.json` 的 `logging.level=INFO`，DEBUG 级原始返回默认不落盘。

### 4.1 核心判据行（INFO 级，注册发生时必打）

```
2026-10-31 HH:MM:SS [INFO   ] dailycheck.mihoyo: 设备注册结果：deviceLogin retcode=<X>，saveDevice retcode=<X>
```

- **retcode=0（或 200）= 服务端接受新身份**，本次联调通过；
- 出现其它 retcode = 按 §5 处置，原文贴进记录表；
- 该行**只在绑定缓存未命中时出现一次**（每 账号+游戏+设备+代理 一次）。**2026-10-31 更新：三款的注册行都已被消费**（星铁/绝区零=2026-10-30 03:50，原神=绑定缓存命中）——观察期内**不会再出现**，除非设备身份再次变更或清理 `logs/mihoyo_binding.json`。此行今后的用途是「下次换身份时的判据」，观察期盯的是 §4.2/§4.3。

### 4.2 失败信号（WARNING 级）

```
… [WARNING] dailycheck.mihoyo: 设备注册失败（不影响查询）：…
… [WARNING] dailycheck.main: 原神(旅行者) -> 查询失败：查询异常：接口 retcode=1034：触发风控…
… [WARNING] dailycheck.main: 绝区零(绳匠) -> 查询失败：查询异常：接口 retcode=10041：风控拒绝…
```

（后两行是 2026-10-31 00:07 真实样例。1034/10041 在刚换身份后出现**属预期冷却**：等待+换网络可自愈；持续超过 48h 才视为「服务端不接受」，进入 §5 处置。）

### 4.3 结果信号

- 推送成败行：`推送结果 [qmsg] 成功：推送成功` / `推送结果 [serverchan] 失败：…`；
- 每日报表页当格颜色（绿=完成、琥珀=有未完成）与「今日完成」KPI。

### 4.4 判据的取证顺序

自动巡检有等待期，**首日判据用「信息查询」手动触发**：控制台 → 信息查询 → 刷新（米游社系三款都会走同一条 `collect_statuses` → `ensure_device_bound` 链路，控制台侧查询与守护进程代码同源）。查完立刻到运行日志抓 4.1 行。

## 5. 节奏与处置

**观察期 = C2 联调日起 7 天（Day 0 = 联调日）。**

- **Day 0（联调日）**：§2 备份 → §3 换血 → §4.4 手动查询确认三款查询层状态 → 扫码绑一款游戏走全链（**性质已降级为凭证轮换验证**：服务端接受度已被 §0 证实，扫码只换 ltuid/ltoken，选哪款听用户现场定）→ 填记录表 Day 0 行；
- **Day 1-7**：巡检推送**先只开原神**（`config.json` 由**用户手动**改：`accounts` 里其余游戏的 `enabled` 置 false；脚本不许碰 config.json）；每天巡检后看推送与日志，填一行记录表；观察重点是 1034/10041 冷却自愈与推送稳定，不再是「服务端接受度」；
- **处置规则**：
  - `deviceLogin/saveDevice retcode=0` → 通过，继续观察期；
  - 出现 1034/10041 → 记录、等待，48h 内自愈属预期；
  - 连续 2 次真实请求失败 → **停**，贴日志原文等用户决策（红线：失败严禁反复重试换机，每次净增一个已注册设备）；
  - 其它非预期 retcode → 原文贴报告，不猜。
